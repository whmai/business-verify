# 业务验证报告模板

```markdown
# 验证报告：<案例 ID / 功能名称>

- 结论：通过 / 失败 / 部分通过 / 未执行
- 用例版本：<提交或版本>
- 环境：<local/test/staging>
- 数据版本与业务时间：<fixture/快照；时区>
- 执行时间：<ISO 8601>
- 本地运行手册：<绝对路径>
- 证据目录：<绝对路径；内容说明>

## 步骤与证据

| 步骤 | 结果 | 实际观察 | 证据 |
| --- | --- | --- | --- |
| S01 | 通过/失败/未执行 | <脱敏摘要> | <截图/请求 ID> |

## 断言结果

| 层级 | 断言 | 结果 | 实际观察 | 原因或证据 |
| --- | --- | --- | --- | --- |
| UI | <断言> | 通过 | <摘要> | <路径> |
| API | <断言> | 未执行 | 无 | <未获授权> |
| 数据 | <断言> | 失败 | <差异摘要> | <失败行数/查询版本> |

## 风险、清理和回归

- 待确认项：<未能机械验证的规则及原因>
- 环境差异：<与生产的显著差异>
- 清理结果：<已清理，或隔离资源标识>
- 回归动作：<新增/更新的案例>
```

不要在报告中包含密码、令牌、完整个人信息、未脱敏生产响应体或未经批准的生产截图。
